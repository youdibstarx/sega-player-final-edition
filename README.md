# Sega Player Final Édition

نسخة مجمّعة تجمع تطبيق SEGA PLAYER V3 **0.5.10 Secure** بمشغل **ExoPlayer فقط** مع آخر بانل للمدير والمشترك.

## المحتويات
- `android/`: التطبيق 0.5.10 (versionCode 28)، بدون مكتبات VLC.
- `panel/`: لوحة المدير للتفعيل لسنة، مدى الحياة أو تاريخ مخصص.
- `/portal`: صفحة الزبون للدخول بالـMAC وDevice Key وإضافة/تعديل قائمة M3U شخصية واحدة.
- شهر تجريبي تقويمي للأجهزة الجديدة بعد أول تسجيل ناجح؛ الأجهزة السابقة تحتفظ بتفعيلها.

## مظهر التطبيق
من الإعدادات اختر «مظهر التطبيق / Thème / Theme / Tema». تتوفر ثلاثة مظاهر مدموجة: الأسود والأحمر، الأزرق البحري، والأخضر الزمردي. يتغير المظهر فوراً وتُحفظ آخر قيمة على الجهاز بعد إغلاق التطبيق وإعادة تشغيله. تبقى القوائم وبيانات الجهاز والتفعيل كما هي، ويظل المشغل ExoPlayer. لا يلزم تحديث البانل لهذا التغيير.

تتضمن نسخة 0.5.10 الخلفيات الثلاث الأصلية وست بطاقات PNG مشتركة بين التيمات، مدموجة في APK وتعمل دون تنزيل إضافي. النص الفرنسي المرسوم على الصور يبقى كما زوده المالك؛ الأوصاف المخصصة لقارئ الشاشة تتبع لغة التطبيق. الخلفية المحلية المختارة تحل محل خلفية البانل في التطبيق. لا يحتاج هذا التحديث إلى نقل ملفات البانل.

## تشغيل البانل
اتبع [تعليمات التركيب اليدوي](panel/PORTAL_UPGRADE_AR.md). خذ نسخة احتياطية قبل استبدال الكود. لا تحذف `data/` أو قواعد البيانات ولا تغيّر إعدادات البيئة الحالية.
المسارات: `/admin` للمدير، و`/portal` للمشترك. بيانات المدير تُحدد بمتغيرات البيئة الموضحة في [إعدادات الحماية](panel/README_SECURITY.md).

## بناء التطبيق
GitHub Actions يبني النسخة المحمية ويشغّل الاختبارات. للبناء محلياً: Java 17 وGradle 8.13 وAndroid SDK 36، ثم من مجلد `android`:

```sh
gradle :app:testDebugUnitTest :app:assembleHardened
```

معرّف التطبيق والتوقيع المسموح به لم يتغيرا. استعمل مفتاح التوقيع الأصلي لتحديث تثبيت موجود. راجع [تعليمات التوقيع](SECURE_SIGNING.md). أسرار GitHub Actions لا تنتقل تلقائياً من المستودع القديم؛ بدونها يكون ناتج البناء غير موقّع وغير قابل للتثبيت. لا ترفع مفاتيح التوقيع أو كلمات المرور إلى Git.
